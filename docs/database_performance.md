# Database performance

Measure transaction page, count and totals queries against a disposable database populated with representative references, sales and assignments. Include unassigned SKUs and multiple SKUs per FNSKU when comparing results. Timings depend on the number of eligible Finances items and source rows, matched control keys, ledger months, and the viewer’s company scope.

The [benchmark tools](../services/db/supabase/benchmarks/) describe their fixtures and queries.
