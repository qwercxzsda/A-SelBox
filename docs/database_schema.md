# Database schema

The [fresh-install migrations](../services/db/supabase/migrations/) contain the schema, indexes, grants and read interfaces. Finances transactions have stable account-scoped identities, immutable component versions and successful observation memberships. Reference money and ledger data are likewise keyed by the Amazon unit that a later answer replaces. Each row keeps its position so repeated source rows count separately.

Company terms are versioned by SKU. Campaign, promotion and shipment assignments are versioned separately from the product information used to suggest a default. PostgreSQL resolves these keys when amounts are read. Each payout saves its totals and pins the source and assignment versions that reproduce its records.

The independent [daily inventory workflow](inventory_daily_captures.md) publishes stock and replenishment information.
