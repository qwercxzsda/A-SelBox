# Company payout reports

The worker publishes by company, marketplace, currency and marketplace-local posting month. A month becomes eligible two calendar months later. Finances needs complete reconciled coverage. Missing references or blank ownership appear as differences. A missing service fee rate on an attributed product sale or refund blocks that company’s report.

Reports retain the exact source, service fee and final totals. The source and assignment versions pinned by each report reproduce its records. Fixing an input can create a revised report for the same scope. Earlier saved reports keep their amounts. Repeated publication with the same inputs reuses the existing report.

The default assignment job runs separately from sync. It fills a blank campaign, promotion or shipment when every listed product resolves to the same company. For products with only an ASIN it searches the account’s loaded ledger. A later SKU move raises a warning on an existing assignment. An administrator can review the products and explicitly change the assigned company.
